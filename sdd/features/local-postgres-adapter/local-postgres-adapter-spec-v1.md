# Local PostgreSQL Adapter — Specification v1

## Scope

Provide first-class local PostgreSQL support for Anclora Talent while preserving the existing Neon adapter for remote environments.

## Requirements

- `localhost`, `127.0.0.1`, and `::1` PostgreSQL URLs use `pg` and `drizzle-orm/node-postgres`.
- Non-local PostgreSQL URLs continue to use `@neondatabase/serverless` and the existing Neon Drizzle adapter.
- `drizzle-kit push` uses the installed `pg` driver for local PostgreSQL.
- The schema source and migration history remain unchanged.
- Application callers continue to receive the same Drizzle database interface from `getDb()`.
- Local E2E and the dedicated QA identity use the local PostgreSQL database when `DATABASE_URL` points to localhost.
- Production and preview/staging environment configuration remains unchanged.

## Acceptance Criteria

- `npm run db:push` completes against the Docker PostgreSQL URL.
- The local database contains the canonical schema tables.
- `e2e.auth@anclora-talent.test` exists with a bcrypt hash generated by the application password helper.
- Local authenticated login succeeds without contacting Neon endpoints.
- Typecheck, lint, build, and focused DB/auth tests pass.
