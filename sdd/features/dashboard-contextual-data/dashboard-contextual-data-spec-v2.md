# Dashboard contextual data — spec v2

## Cambios

- Todos los CTA de dashboard y nuevo proyecto comparten el tratamiento visual del botón `Nuevo proyecto` del dashboard, incluidos foco, hover y ausencia de elevación.
- El menú de usuario usa la marca `Usuario Talent` / `Talent user` y el cierre de sesión usa el mismo CTA primario.
- Las dos acciones del menú contextual de proyecto ocupan el mismo ancho; eliminar conserva el tono rojo únicamente en hover/foco.
- Los datos del documento reflejan los metadatos importados, el perfil editorial de referencia y la identidad de marca elegida durante la creación.

## Compatibilidad

Los proyectos antiguos sin estos metadatos muestran valores neutros (`Sin especificar`) sin romper el dashboard.
